Transcript retrieval

Otherwise Preyt opens the video in an inactive, muted tab, reads the transcript there and closes the tab right away (usually 2–4 s). That tab uses your normal YouTube session, like opening the link yourself, so it may count as a visit; the video is paused immediately.

Privacy & data sent

When you summarize a video, Preyt sends the transcript text, title, channel, duration, chapter titles and video ID (or, for the metadata-only option, the title and description) directly from this browser to Google’s Gemini API (generativelanguage.googleapis.com), authenticated with your API key. There is no Preyt server.

With a free-tier key, Google may use what you send to improve its products, and people may review it. With billing enabled, the paid-tier terms apply. See the Gemini API terms. Recent results are kept in memory until the browser closes.
